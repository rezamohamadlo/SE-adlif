# Project documentation

Main result comparisons remain in [reports](../reports/). Documentation is organized separately:

- [Experiments](experiments/): preparation, launch and monitoring guides, including the [SSC loss diagnostic](experiments/ssc-loss-diagnostic-guide.md).
- [Audits](audits/): evidence reviews and reproduction investigations, including [SSC](audits/ssc-reproduction-audit-2026-10-18.md), [SHD*](audits/shd-reproduction-audit-2026-10-18.md) and the [per-seed results audit](audits/results-audit-2026-10-18.md).
- [Transfers](transfers/): [ECG](transfers/ecg-transfer-2026-10-19.md) and [SSC](transfers/ssc-transfer-2026-10-19.md) import records. Their shared machine-readable manifests live in [results/provenance](../results/provenance/).

Per-run configs, metrics, checkpoints and cost evidence remain with their training seed directories. Historical material already under `reports/archive/` is preserved as an archive.
